## Chi tiết lỗi Loại B (code bug — cần dev fix)

### B1: GET /api/v1/prescriptions/{id}/print-history

**Lỗi:** `System.InvalidOperationException: A parameterless default constructor or one matching signature (System.String Id, System.DateTime PrintedAt, System.String PrintedBy, System.String PrinterName) is required for ProDiabHis.Application.Pharmacy.Prescriptions.PrintHistoryItem materialization`

**Root cause:** `PrintHistoryItem` là positional record (`record PrintHistoryItem(string Id, DateTime PrintedAt, string PrintedBy, string PrinterName)`) nhưng Dapper không thể map kết quả SELECT vào positional record — cần chuyển sang `record class` có property hoặc dùng `QueryAsync<dynamic>`.

**File:** `src/ProDiabHis.Application/Pharmacy/Prescriptions/PrescriptionHandlers.cs` (class `GetPrintHistoryHandler`)  
**Ghi chú:** Schema đã đúng (đã thêm `printer_name`), chỉ cần sửa DTO type.

---

### B2: GET /api/v1/branches/{id}/users

**Lỗi:** `System.InvalidOperationException: A parameterless default constructor or one matching signature (System.String UserId, System.String FullName, System.String Email, System.Boolean IsPrimary) is required for ProDiabHis.Application.Branches.UserBranchDto materialization`

**Root cause:** `UserBranchDto` là positional record — Dapper không thể instantiate. Cùng pattern với B1.
